i18n Bonsai

tending your i18n files

A desktop app for editing and AI-translating your JSON localisation files. See all your locales side-by-side, translate missing strings with one click, and keep translator context right next to each key.

Get Started See how it works Download

Features

Everything you need to keep your translations tidy

Side-by-side grid

All locales displayed in a single scrollable grid. Spot missing translations instantly and edit any cell inline.

AI translation

Translate missing strings with one click using OpenAI GPT. Fill an entire locale column or just a single row.

File groups

Open any file in a group and all sibling locale files load automatically — admin.en.json, admin.de.json, etc.

Per-key context

Add translator hints to any key via a context.json sidecar file. Context is sent to the AI to improve translation quality.

Search & filter

Full-text search across keys and values. Toggle a "show untranslated only" filter to focus on what still needs work.

Dark mode

Full dark/light theme support. Your preference is saved automatically between sessions.

How it works

From zero to translated in three steps

1

Open your files

Click Select Source and pick any locale file. All related locale files in the same directory load automatically.

2

Edit & translate

Edit cells directly in the grid, or click Translate ↓ on any column to fill all missing translations with AI.

3

Save all locales

Click Save All Locales to write every locale file back to disk in one shot.

Setup

Download the latest release for your platform from the GitLab releases page. i18n Bonsai runs as a standalone desktop app — no installation of Node.js or other runtimes required.

On first launch, go to Settings (the cog icon) and enter your OpenAI API key. This is only required if you want to use AI translation. The key is stored locally in your browser/app preferences and never sent anywhere other than OpenAI.

You can also set a global context — a free-text description of your app that is included in every translation prompt to improve quality. The primary language is determined automatically from the locale file you open.

Opening files

Click Select Source to open a file picker. Choose any one of your locale JSON files — i18n Bonsai automatically loads all other locale files in the same directory alongside it.

For example, selecting en.json will also load de.json, zh-CN.json, and any other locale files present in that directory.

i18n Bonsai remembers the last translation set you had open and restores it automatically on next launch — no need to re-select your files each time.

Editing translations

Click any cell in the grid to edit its value. The primary language column is displayed for reference.

Action Where Effect
Translate Lang ↓ Column header AI-fills all empty cells in that locale
Translate Row Row action menu Retranslates all non-primary locales for that key
Translate Item Item action button Retranslates individual item for that key
Add Locale Toolbar Adds a new empty locale column
Add Row Row action menu Adds a new i18n key and a (optional) translation context
Filter untranslated Toolbar icon Shows only rows with at least one empty value

When you are done, click Save All Locales to write all changes to disk. A confirmation dialog shows which files will be overwritten. Keys are automatically sorted alphabetically by key and sub-key on save, keeping your files tidy and diff-friendly.

AI translation

i18n Bonsai calls the OpenAI Chat Completions API directly from the app. You choose the model in Settings (GPT-4o is the default).

Each translation request sends:

  • The source language and target language
  • Your global context (set in Settings)
  • Any per-key context hint for that row
  • The source string to translate

The Translate ↓ button in the column header fills only empty cells — it never overwrites existing translations. Use the per-row translate button to force a re-translation of all locales for a specific key.

Note: API calls are billed to your OpenAI account at standard rates. Translating large files with many keys can incur costs, especially with GPT-4.

Context hints

For each translation key you can store a short hint that helps the AI understand what the string is used for. These hints are kept in a special context.json file that i18n Bonsai creates and manages automatically alongside your locale files.

When you translate a key, the per-key context from context.json is included in the prompt sent to the AI, improving translation accuracy for ambiguous or UI-specific strings.

File naming convention

Locale files are named using the locale code as the filename: en.json, de.json, zh-CN.json, etc. All locale files live in the same directory.

Source or translation files must contain at least {}.

The only special file is context.json, which holds per-key translator hints and is handled separately by i18n Bonsai — it is not treated as a locale.

Settings

Open Settings via the cog icon in the top-right corner.

Setting Description
ChatGPT API Key Your OpenAI API key. Stored locally, never transmitted except to OpenAI.
Translation Model The OpenAI model to use for translations (e.g. gpt-4o, gpt-4-turbo).
Global Context A description of your app included in every AI translation prompt. Helps the AI produce more accurate, in-context translations.

Troubleshooting


Source or translation files must contain at least {}

A locale column is missing

If a locale file exists on disk but does not appear as a column after loading, the file is likely empty. i18n Bonsai automatically loads empty locale files and adds them to the grid with no translations. If the column still does not appear, verify that the file name follows the expected naming convention (e.g. de.json for the de locale).

A locale file is silently ignored

i18n Bonsai requires all JSON files to be well-formed. A file that contains invalid JSON (for example a missing closing brace, a trailing comma, or other syntax errors) is silently skipped during load — it will not appear as a column and its contents will not be loaded.

Fix: Open the offending file in a text editor or JSON validator, correct the syntax, and reload the source in i18n Bonsai.

The grid is empty after opening a directory

This happens when the primary language file (determined by the file you selected) is empty or could not be read. i18n Bonsai will seed the grid with a placeholder newKey row so you can start adding content. If you intended to load existing translations, make sure the file you selected contains valid JSON.
